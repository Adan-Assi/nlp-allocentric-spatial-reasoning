# Data Folder

This `data/` directory contains the datasets and intermediate files used throughout the project for the three supported cities:

- `manhattan/`
- `philadelphia/`
- `pittsburgh/`

## Original RVS Map Files (Manual Download Required)

The original RVS map files for each city are **not included in GitHub** because they are too large.

They must be downloaded manually from the following Google Drive folder:

**Drive Link:**  
https://drive.google.com/drive/folders/1bvxNeIlN1SKeup6aJgIUzWrQ8v-cL9Yq

After downloading, place the relevant files inside their corresponding city folders under `data/`.

---

## Files Stored Per City

Each city folder contains original data files as well as generated outputs from scripts that are expensive and time-consuming to rerun.

### Required / Generated Files

### `<city>.json`

The original RVS dataset file for that city.

Contains the navigation instructions and associated metadata.

Example:

- `manhattan.json`
- `philadelphia.json`
- `pittsburgh.json`

---

### `<city>_silver_standard.parquet`

Generated by:

```bash
python scripts/batch_labeling.py
````

This file contains the silver-standard labels for the instructions of that city.

Since generating this file can take a long time, it is stored directly in the repository workflow rather than recreated each time.

Example:

* `manhattan_silver_standard.parquet`

---

### `underspecified_variants.json`

Generated by:

```bash
python scripts/underspecify_instructions.py
```

Contains masked / underspecified instruction variants created from the original instructions by removing landmarks, directional cues, or both.

These are used for ambiguity and underspecification evaluation.

---

### `underspecified_variants_labeled.json`

Generated by:

```bash
python scripts/label_variants.py
```

Contains the masked instruction variants after Oracle 2 labeling.

Each variant receives a label such as:

* `Answerable`
* `Ambiguous`
* `Contradictory`

This file is required for downstream evaluation and reporting.

---

## Notes

Some of these scripts may take hours to complete depending on the city and machine resources.

To avoid unnecessary recomputation, these generated files are kept inside the `data/` directory and reused across experiments.
